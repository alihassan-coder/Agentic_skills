# Agentic Skills

## What is a Skill?

A **skill** is a packaged set of instructions, knowledge, and (optionally) scripts that teaches an AI agent how to perform a specific kind of task. Instead of explaining the same workflow to the agent every time, you write it once as a skill — and the agent loads and follows it whenever that task comes up.

Think of a skill as a **reusable playbook** for the agent:

- **Instructions** — step-by-step guidance on how to do the task
- **Context** — domain knowledge, conventions, or rules the agent should follow
- **Resources** — optional helper scripts, templates, or reference files

## Why use Skills?

- **Consistency** — the agent does the task the same correct way every time
- **Reusability** — write once, use across many sessions and projects
- **Specialization** — turn a general-purpose agent into an expert for your workflow

## Structure

A typical skill lives in its own folder with a `SKILL.md` file:

```
my-skill/
├── SKILL.md        # name, description, and instructions
└── (optional)      # scripts, templates, references
```
